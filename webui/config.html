Inject policy
Adds the Markdown memory operating instructions to every new chat.
Inject semantic recall
For each first user message, searches for relevant vault notes and injects them as context.
Embedding endpoint (internal)
Ollama-compatible /api/embed endpoint, for example http://<internal.example>:11434/api/embed. Leave empty to disable semantic recall. After saving, the value is shown masked.
Embedding model
Model name as used by the provider (default granite-embedding:278m).
Notes per recall
1 to 10 most similar notes (default 3).
Minimum message length
Shorter first messages skip recall (characters, default 5).
Search timeout (seconds)
Maximum duration of a single recall search (default 20).
Maximum note length (characters)
Truncation length per injected note (default 6000).
Vault path
Absolute directory containing the Markdown notes inside the Agent Zero container.
Index database
Path to the SQLite vector index filled by the indexer.
Embedding dimensions & provider timeout
Dimension of the model (Granite 278m = 768) and the provider HTTP timeout in seconds (default 15).
